# bd-agua-guilherme-machicua-.
O SGD-Água Beira é um sistema de gestão de falhas e distribuição de água potável para a cidade da Beira, criado para responder à crise crónica de abastecimento. Cidadãos, operadores e sensores reportam falhas (fugas, ruturas, baixa pressão, falta de água ou água turva) por bairro e zona.
